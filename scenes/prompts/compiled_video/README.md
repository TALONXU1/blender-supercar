# compiled_video/ — 图生视频提示词

由 `../video_library.json` 经 `../build_video_prompts.py` 生成。**不要手改**，改 JSON 重跑。

```bash
python scenes/prompts/build_video_prompts.py
```

## 用法

首帧用 `../compiled/<同 ID>.txt` 出的图，命名 `S2-01.png`，喂进图生视频模型，正文粘这个文件。

```
图 → compiled/S2-01.txt   → 出图 S2-01.png（首帧）
视频 → compiled_video/S2-01_vid.txt  +  S2-01.png
```

## 每个文件的结构

```
# 场景名
# 画风 ST3   时长 6s   motion 54 词
# 首帧 S2-01.png（compiled/ 里对应的关键帧）

<motion：40–80 词，一个主动作 + 方向 + 速度 + 时长>

Keep: <2–3 个必须不变的东西>
Avoid: <2–3 个视频特有的漂移>
```

## 阈值

| 检查 | 阈值 | 超了说明 |
|---|---|---|
| motion 词数 | 40–80 | 又在写静态描述，模型会重构画面而不是让它动 |
| 方向词 | 必含 | 写"移动"等于没写，模型自己摇 |
| 关键帧词汇 | 禁含 `mm lens`/`degrees`/`kelvin` | 写串层了，这些属于关键帧 |

脚本全查，`--check` 只查不写。

## 时长分布

| 时长 | 用途 | 文件 |
|---|---|---|
| 3 s | 近距逼近、单次事件 | S3-03 隧道、S4-01 迎车、S8-02 逆光冲入 |
| 4 s | 平移跟拍、一个动作完成 | 10 个 |
| 5 s | 过弯、穿越、场景内运动 | 8 个 |
| 6 s | 爬坡、升降、慢变化 | S2-01、S2-02 |

物理对照：3 秒车从远处到占满画面是可以的；6 秒爬 40 米落差是可以的；3 秒跑完 300 米不行。

## 平台适配

| 平台 | 时长上限 | 注意 |
|---|---|---|
| 可灵 / Seedance | 5–10 s | 上面 3/4/5/6 s 直接用 |
| Runway Gen-3 | 5–10 s | 超过 10 s 要拆镜头 |
| Pika | 3–4 s | 5/6 s 的压到 4 s，砍 Keep 里第三项 |
| SVD | 2–4 s | 只保留 motion 第一句 |

压时长时砍 Keep，不要砍 motion——motion 砍了就没动作了。

## 最常见的一处错

把 `compiled/` 的关键帧提示词整段粘到视频模型里。图提示词 150+ 词里 90% 是静态描述，视频模型会把它们当成"要重建的画面"，于是给你一张略微抖动的静止图。

正确做法：只粘 `_vid.txt` 的正文，40–80 词，首帧用图锁住。
