# scenes/ — F1 场景库

给两条线共用的一份场景定义：**Blender 程序化渲染**（`pipeline/`）和 **AI 视频模型提示词**（Veo / Sora / Kling / Seedance）。

现在项目里只有两个赛道数据包（Silverstone、Monza），跑的是一种天气（英国午后）。这个文件夹解决"接下来渲什么、怎么说"——先把场景说清楚，再决定建不建。

## 文件

| 文件 | 内容 | 什么时候看 |
|---|---|---|
| [F1_CIRCUITS_MASTER.md](F1_CIRCUITS_MASTER.md) | 历届赛历总表：2026 全 24 站 + 已退出赛道，地点/类型/气候/视觉锚点 | 想换赛道、想查某站真实长什么样 |
| [SCENE_OPTIONS.md](SCENE_OPTIONS.md) | **8 个精选场景卡 + 4 个备选**，含天气/时段/光照数值/AI 提示词/落地代价 | 定下一个要拍什么 |
| [weather_matrix.md](weather_matrix.md) | W1–W10 天气预设库，参数化，可直接拼进提示词 | 换天气、做同赛道多版本 |
| [scene_schema.md](scene_schema.md) | 场景卡字段规范 | 要脚本批量生成 / 加新场景 |
| [prompts/](prompts/) | 每个精选场景一份可整段复制的提示词包 | 直接出图 / 出视频 |

## 三条使用路径

**只想出 AI 视频**：读 `SCENE_OPTIONS.md` 挑一个 → 打开 `prompts/0X_*.md` → 抄提示词 → 不用管 Blender。

**要在 Blender 里真渲染**：看场景卡里"落地"那一节，写着这个赛道 `track_data/` 有没有数据、要新建哪些资产、EEVEE 里天气怎么实现。

**要批量做多版本**：`weather_matrix.md` 选天气 × `SCENE_OPTIONS.md` 选地点，交叉组合，字段按 `scene_schema.md` 填。

## 和现有工程的关系

- 现在 `track_data/` 只有 Silverstone + Monza，`build_track.py` 换 3 个参数重跑就能生成新赛道，但**街道赛（摩纳哥/新加坡/巴库/维加斯）OSM 里没有 circuit relation**，得手绘中心线或从官方赛道图拟合，代价高一个量级。场景卡里都标了。
- 现有 `v5_env.py` 生成的环境是银石专用（草地缓冲带、砾石坑、6 座看台、机库）。换到斯帕要加森林；换到蒙扎要改看台为红色钢结构+直道；换到街道赛基本要重写环境层。
- 天气目前只有一套太阳+补光（`V5_07_Lighting`）。`weather_matrix.md` 里 W4 之后（阴/雨/雾/夜）都需要改光照和加体积介质，属于环境层工作，不是调个参数。

## 选场景的三条硬约束

1. **这个场景在视频里能不能认出来**——观众三秒内得知道"这是摩纳哥"。认不出的场景不值得渲。
2. **天气是不是这站的性格**——斯帕没雨、新加坡没灯，等于换了个地方。
3. **资产能不能复用**——银石/蒙扎已有几何，改天气比重建赛道便宜十倍。
