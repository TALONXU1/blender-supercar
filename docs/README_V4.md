## 1. 模型优化（建模）

| 部位 | 处理 |
|---|---|
| **四轮总成** | 全部按参数化重建（老版本轮胎/轮辋是错位旋转的散件） |
| 轮胎 | 714 mm 外径、前 345 / 后 425 mm 宽的闭合截面旋转体，含胎肩圆弧、胎侧鼓起、胎冠微拱 |
| 轮辋 | 18 寸筒身 + 抛光外唇 + 10 根锻造辐条（12 段放样、涡轮微扭、Bevel 硬化法线） |
| 中央锁止 | 6 面阳极氧化金锁止螺母 |
| 刹车 | 碳陶盘（72 段环体 + 44 个沉孔）+ 红色阳极卡钳 + 碳纤导风罩 + 可驱动的过热发光环 |
| 胎壁贴花 | 按轮胎截面插值生成共形环带，UV 用极坐标圆盘映射（PIRELLI / P ZERO 不再"贴纸感"） |
| **尾翼** | 重做：双元素翼型（主翼 0.30 m 弦长 + DRS 副翼）+ 收窄端板（±0.50 m，带倒角）+ 中央吊架 + DRS 作动筒 |
| **扩散器** | 重做：弧形底板 + 6 片导流栅（老版本是伸出车尾的 6 片"黑刀片"） |
| **表面** | 全部网格重算法线 + 按 34° 角度平滑（硬边保留），消除平直塑料感 |
| **贴花系统** | 改为 **BVH 射线投影**：按贴花 UV 坐标系逐格投射到车体 BVH 表面，生成共形网格；不再有悬浮卡片、不再投射到地面 |
| **材质** | 碳纤程序化斜纹凹凸、哑光海军蓝车漆（金属度 0.05 / 粗糙度 0.44 / 清漆 0.14）、橡胶微观颗粒、金属各向异性 |

## 2. 骨骼绑定（Rig）

骨架 `RIG_F1_Race`，19 根骨骼，**分层控制**：

```
Bone_Root                  整车世界位移
└ Bone_Heading             航向角（偏航）
  ├ Bone_Body              车身姿态：俯仰 / 侧倾 / 升沉（几何中心附近为枢轴）
  │  ├ Bone_Steering_Wheel 方向盘（绕自身轴）
  │  ├ Bone_DRS            尾翼 DRS 铰链
  │  ├ Bone_Aim            摄影机瞄准点
  │  └ Bone_CamAnchor      车载机位挂点
  ├ Bone_Susp_FL/FR/RL/RR  悬挂行程（限位 -60 / +30 mm）
  │  └ Bone_Hub_FL/FR      转向节（绕垂直轴 ±38°）
  │     └ Bone_Wheel_FL/FR 轮轴（绕 X 轴滚动）
  └ Bone_Susp_RL/RR → Bone_Wheel_RL/RR
```

零件按类别刚性绑定（Bone Parent，保持世界矩阵），共 236 件：
- 旋转件（轮胎 / 轮辋 / 辐条 / 刹车盘 / 气门嘴 / 胎壁贴花）→ `Bone_Wheel_*`
- 静止件（卡钳 / 导风罩）→ `Bone_Hub_*`（随转向转动，符合真实结构）
- 方向盘总成 + 换挡灯 → `Bone_Steering_Wheel`
- DRS 副翼 / 作动筒 → `Bone_DRS`
- 其余车体、悬挂、翼片 → `Bone_Body`

### 控制器与驱动器（可动画属性）

| 属性 | 范围 | 驱动对象 |
|---|---|---|
| `steer` | -40…40° | 前轮转向节 + 方向盘（5:1 减速比） |
| `wheel_spin` | 弧度 | 四轮滚动；后轮再乘 `rear_slip` |
| `rear_slip` | 0.8…3.0 | 后轮空转打滑（烧胎） |
| `drs` | 0…1 | 副翼 -16° 开度 |
| `brake_heat` | 0…1.5 | 刹车盘发光强度（Emission ×9） |
| `susp_f` / `susp_r` | -60…30 mm | 前后悬挂行程 |
| `steer_ratio` | 1…12 | 方向盘传动比 |

全部驱动器使用 **简单表达式**（无 Python 依赖），打开工程即可实时响应。

### 现实赛车逻辑（F1 口径）
- **滑移角**：入弯 <1°，弯心最大 **4.5°**，出弯 36 帧内回正 —— 不是漂移车，F1 干地几乎不打滑
- **弯速**：弯心 160–170 km/h（R≈73 m，横向 2.9 g），接近真实中高速弯
- **转向**：前轮转角上限 ±9°，反打只是几度修正
- **车身**：滚转 ≤2.0°、俯仰 -1.6…+1.2°（悬挂极硬），升沉仅毫米级
- **起步**：后轮短暂空转 1.55×、车体轻微后坐、发车灯同步熄灭
- **换挡**：按车速推算 8 档，每次升档扭矩中断 → 车头轻点 + 升沉抖动
- **重刹**：车头下压、前悬压缩、刹车盘过热发光、尾部刹车灯增亮、短促锁死胎痕
- **出弯**：DRS 关闭、后轮 7% 动力滑移、俯仰回正加速
- **无轮胎烟、无长胎痕**（干地光头胎的正常表现）

时间线标记自动切换摄影机（`scene.timeline_markers[].camera`）。

## 7. 音乐卡点（After Hours / BPM 108）

- 分析：`pipeline/analyze_audio.py` → 自相关测速得 107.67 BPM，归一化取整 **108 BPM**（拍长 0.5556 s = **13.334 帧 @24fps**）
- 选用段落：**240.814 s 起的 8 拍 downbeat**，54 拍 × 0.5556 s = **30.00 s**，正好等于 720 帧
- 段落能量扫描：bar 3–5（6.7–13.3 s）最强 → 安排全速直道；bar 6–9 转弱 → 安排重刹入弯与弯心；bar 10+ 回升 → 出弯加速冲线
- 切点全部吸附到拍：帧号 = `1 + j × 13.334`

## 9. 赛道几何修复（T1 右 90° + T2 左 90°）

**问题**：旧版弯道曲率在 190 帧内累加了 **206° 总转角**，赛道带绕成一个环，远端压回起点附近 → 第 8 秒起出现赛道自交穿模。

**修复**：改为标准 F1 赛道段结构，净转角 ≈ 0：

| 路段 | 帧 | 里程 | 说明 |
|---|---|---|---|
| 发车直道 | 1–334 | 0–900 m | 0 → 300 km/h |
| T1 右 90° | 334–490 | 900–1200 m | 半径 **85 m**，弯速 132 km/h，横向 **1.7 g** |
| 短直道 | 490–500 | 1200–1290 m | 132 → 166 km/h |
| T2 左 90° | 500–614 | 1290–1500 m | 半径 **83 m**，弯速 162 km/h，横向 **2.5 g** |
| 冲线直道 | 614–720 | 1500–1779 m | 166 → 300 km/h |

验证（`pipeline/check_track.py`）：
```
total distance : 1779 m
net heading    : 7.9°          <- 净转角，非环状
OK: no self-intersection (min gap >= track width)
min non-adjacent centerline gap: 30.0 m  (track width = 12.8 m)
```
