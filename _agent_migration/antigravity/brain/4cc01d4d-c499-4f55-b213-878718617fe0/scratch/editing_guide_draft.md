## 编辑指南（README.md 版，替换"改东西的三条路"第 1 条）

**1. 改单个物件 / 整组挪动**（挪看台、换广告板颜色、删一根灯柱）
直接开 `LATEST/v5_stage_anim.blend`（只改环境、要重跑动画时开 `v5_stage_env.blend`）。

**整组挪动靠 Empty 父级**：每座看台、每座天桥、每块大屏、每组刹车牌、每个裁判点、起终点龙门架（含发车灯）都有一个 Empty 父级，放在该组的几何中心。

- Outliner 里点那个 Empty（不是子零件）→ `G` 移动 / `R` 旋转（`G Z`、`R Z` 锁轴），整组一起走。
- 只想改组里某一件：展开 Empty，选子对象再 `G`/`R`/`S`。
- 子对象的原点在各自几何中心，不在 1 km 外的世界原点。

| Empty 名 | 管什么 |
|---|---|
| `V5_Stand_*` | 一座看台的阶梯块、后墙、顶棚、VIP 带、立柱、桁架、旗杆、旗 |
| `V5_Bridge_*` | 人行天桥 |
| `V5_Screen_*` | 大屏 |
| `V5_BrakeBoards_*` | 一个弯的 150/100/50 m 刹车牌 + 立柱 |
| `V5_Marshal_*` | 裁判点小棚 + 顶灯 |
| `V5_Gantry*` | 起终点龙门架 + 5 盏发车灯 |

（Empty 实际名字以 env 最终报告为准）

**重复小零件按看台合并**：每座看台的立柱、桁架横梁、旗杆、旗面各合成一个网格（旗面保留多材质），维修区 60 条车位线合成一个网格。大件或单独有意义的件（阶梯块、后墙、顶棚、VIP、每块广告板、路肩）仍是独立对象。想改单根柱子：选中合并网格 → `Tab` 进编辑模式 → `L` 选相连块 → `G`。

Outliner 按集合找：

| 集合 | 内容 |
|---|---|
| `V5_01_Road` | 路面、赛车线、边线、路肩、起跑线、pit lane |
| `V5_02_Terrain` | 地面、草地缓冲带、砾石坑、天空穹顶 |
| `V5_03_Barriers` | 护栏、防护网立柱 |
| `V5_04_Stands` | 6 座看台（每座一个 Empty 父级） |
| `V5_05_Pit` | 维修墙、车库楼、楼顶看台、车位线 |
| `V5_06_Props` | 广告板、刹车牌、大屏、天桥、裁判点、龙门架、机库、灯柱 |
| `V5_07_Lighting` | 太阳、补光 |

对象数：env NNN / anim NNN（原 919 / 948）。
