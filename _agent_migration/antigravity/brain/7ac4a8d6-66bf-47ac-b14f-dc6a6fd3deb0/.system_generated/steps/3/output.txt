**Open Design Motion** is an open-source, local-first motion-design and video generation workflow integrated into **Open Design** (an AI collaborative design agent workspace)[1][2]. Positioned as an open-source alternative to tools like *Claude Motion*, it allows users to generate programmable motion graphics, UI mockups, and promo videos using AI agents[3][1][4].

### How It Works
1. **Prompt-to-Code:** You provide a text prompt describing the video or animation you want, alongside brand assets like logos, screenshots, or style notes[5][2].
2. **AI Agent Generation:** An AI agent writes the underlying code (such as HTML, CSS, and GSAP animation scripts)[5]. 
3. **Rendering:** The platform (using rendering engines like HyperFrames) compiles the code into an MP4 video file[5].
4. **Editable Source:** Unlike black-box generative video models (like Runway or Kling)[3] that only output a flat video file, Open Design Motion retains the underlying project structure. You can directly edit text, timing, colors, layout, and scene length[5][2].

### Key Features
* **Model Flexibility:** Because it's open-source, you aren't locked into a single ecosystem; it can be run using various AI models and agents[1][4].
* **Local-First & Open Source:** Hosted via projects like `nexu-io/open-design`, allowing for local deployment or use with bring-your-own-API keys[6][4][2].
* **Built-in Templates & Use Cases:** Includes templates tailored for product promos, UI morphs, showreels, kinetic typography, and storytelling layouts[4].
